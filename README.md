# FeedMestre Estúdio

Aplicativo para Windows x64 que renderiza Reels e cortes de vídeo no computador vinculado à sua marca. Os vídeos ficam disponíveis no FeedMestre para revisão.

**[Baixar o Estúdio 0.1.1 para Windows x64](https://github.com/ceviqtech/feedmestre-estudio-downloads/releases/download/v0.1.1/FeedMestre-Estudio-x64.exe)** · 362 MB

Depois de instalar, abra **Estúdio** no painel da marca, gere um código de vínculo e cole-o no aplicativo.

O instalador 0.1.1 não possui assinatura Authenticode. As notas da versão incluem o SHA-256 para conferir o arquivo. [Notas da versão](https://github.com/ceviqtech/feedmestre-estudio-downloads/releases/tag/v0.1.1)
